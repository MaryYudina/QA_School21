# Задание 7. Составить тестовый сценарий

Тестовый сценарий по процессу «Как поступить в Школу 21»

* Название тестового сценария: Проверка процесса "Как поступить в Школу 21"
* ID теста: TS-001
* Описание: Проверка возможности прохождения вступительного испытания на сайте https://21-school.ru/admission
* Предусловия: Пользователь должен иметь выход в интернет
* Шаги:
   1. Открыть веб-браузер

   2. Перейти по URL: https://21-school.ru/admission
   3. Перейти к форме "Заявка на поступление"
   4. Выбрать кампус
   5. Выбрать программу
   6. Ввести корректный адрес электронной почты
   7. Нажать на чекбокс "согласие на обработку перс.данных"
   8. Нажать на кнопку "поступить"
* Ожидаемый результат: Пользователю на указанную почту в форме "Заявка на поступление" пришло письмо с информацией об условии поступления на отборочный интенсив
* Фактический результат: Пользователю на указанную почту в форме "Заявка на поступление" пришло письмо с информацией об условии поступления на отборочный интенсив
