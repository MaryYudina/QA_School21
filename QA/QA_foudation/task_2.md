# Задание 2. Виды тестирования


ISTQB (International Software Testing Qualifications Board) классифицирует виды тестирования по нескольким критериям, включая уровни, типы, методы и техники. В рамках программы ISTQB существует сертификация, охватывающая различные аспекты тестирования. 
Основные виды тестирования по ISTQB:

- Уровни тестирования:
  - Модульное тестирование: Проверка отдельных компонентов программного обеспечения. 
  - Интеграционное тестирование: Проверка взаимодействия между компонентами или системами. 
  - Системное тестирование: Проверка всей системы на соответствие требованиям. 
  - Приемочное тестирование: Проверка системы пользователями или заказчиками на соответствие их потребностям. 

- Типы тестирования:

  - Функциональное тестирование: Проверка соответствия функциональности системы требованиям. 
  - Нефункциональное тестирование: Проверка характеристик системы, таких как производительность, надежность, безопасность и т.д. 
  - Структурное (белый, черный, серый ящик) тестирование: Тестирование на основе внутренней структуры и логики работы системы. 

- Методы тестирования:
  - Эквивалентное разбиение: Разделение входных данных на классы эквивалентности. 
  - Анализ граничных значений: Тестирование значений на границах допустимых диапазонов. 
  - Тестирование по таблицам переходов состояний: Тестирование на основе модели конечного автомата. 
  - Позитивное и негативное тестирование: Проверка корректных и некорректных входных данных. 

- Методологии тестирования:
  - Гибкое тестирование (Agile Testing): Подход к тестированию, соответствующий гибким методологиям разработки. 
  - Тестирование на основе моделей (Model-Based Testing): Использование моделей для генерации тестов. 
  - Тестирование мобильных приложений: Специализированное тестирование для мобильных устройств. 
  - Тестирование производительности: Оценка производительности системы при различных нагрузках. 

- Управление тестированием:
  - Планирование тестирования: Разработка стратегии и плана тестирования. 
  - Организация тестирования: Настройка процессов и ресурсов для тестирования. 
  - Автоматизация тестирования: Использование инструментов для автоматизации выполнения тестов
